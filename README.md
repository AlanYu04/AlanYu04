### 我关心的研究问题

我很希望接下来能多做一些和**数据**有关的课题，尤其想弄清楚几件事：

- **数据有没有用**：怎样判断一批数据对模型、对具体任务是否有帮助？
- **预算有限，怎么选数据**：在采集、标注和训练成本有限的情况下，怎样选出更值得投入的数据？
- **哪些数据影响更大**：能否在训练过程中识别出对模型表现影响较大的数据，并进一步理解它们带来了什么影响？

无论是目前在做的具身智能研究，还是未来可能探索的 **AI for Science（AI4S）**，我都觉得，理解数据如何影响模型、如何把数据用好，是一件值得长期投入的事。这些问题也和企业研发中的实际选择联系得很紧：数据要不要继续收、标注预算怎么分配、下一轮训练该用哪些样本。如果研究能为这些决策提供一些可靠的依据，帮助大家在有限成本下更好地选择和使用数据，我会觉得很有意义。
